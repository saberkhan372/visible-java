The folded pane is worth opening once per example. The Java + Processing version is the whole course on one screen: your sketch was always a class, your variables were always fields, your functions were always methods, and something was always calling main. Processing just never showed you the wrapper.

Want to actually run Java rather than read it? Copy a complete pane into the Java environment chosen for this course. Every plain-Java pane is designed to compile on its own; the Processing panes need the Processing library described on the Setup page.

Using these well

  • Predict before you run. Read the AP Java pane and write down what you think it prints. Then run it. Then explain any difference. That loop is the single most valuable study habit in this course — over a third of the multiple choice is code analysis.
  • Type the middle pane by hand once. Copying teaches you nothing about where semicolons and braces go. You will hit the file-name rule and the static rule on your own, which is how they stick.
  • Change one thing. Take the AP pane, change a bound or a starting value, predict the new output, run it. Small deliberate edits beat re-reading.
  • Then go to Port and do the same thing to a sketch you wrote yourself.
