Get ready · about 15 minutes

Your first sketch

Processing is a free editor for writing small Java programs that draw. This page gets it installed and running one sketch. You are done when a circle slides down a window on your screen.

Five steps

Install, open, run

  1. Download Processing 4

    Go to processing.org/download, choose your operating system, and follow the instructions there. It is free.

    Processing comes with its own copy of Java, so you do not need to install Java to run sketches.

    Can’t install software? School laptops sometimes block it. Ask your tech team early, or email ahead. A browser-only option is being tested, but every workshop activity is checked against desktop Processing.

  2. Open it

    The first time, your computer may ask you to confirm that you want to open an app downloaded from the internet. Say yes. An editor window opens with an empty sketch.

  3. Check that you are in Java mode

    The mode menu is in the top-right corner of the editor. It should say Java, which is the default. If it says anything else, such as p5.js or Python, open that menu and choose Java.

  4. Paste this sketch and press Run

    Run is the round ▶ button at the top left. The keyboard shortcut is ⌘R on a Mac or Ctrl+R on Windows and Linux.

    float y = 0;

void setup() {
  size(400, 400);
}

void draw() {
  background(255);
  circle(200, y, 40);
  y = y + 2;
}

    Expect  A square white window opens. A white circle with a black outline starts at the top center, slides straight down, and leaves the bottom in about three and a half seconds. At first you see only the circle’s lower half, because its center starts on the top edge.

  5. Save it, and open the workshop files

    Choose File → Save. Processing saves every sketch as a folder holding a .pde file with the same name, so MovingBall/MovingBall.pde. Name sketches with letters, numbers, and underscores, starting with a letter.

    To open the workshop sketches, unzip session-1-files.zip and use File → Open on, for example, FrameByFrame/FrameByFrame.pde.

If it doesn’t work

First-run problems

What you seeWhat it usually means
Run does nothing, and there is red text in the bottom panelThat panel is the console. The red line is a compiler error, usually a missing semicolon or bracket from pasting. Copy the sketch again with the Copy button above.
A window flashes open and closesThe sketch hit an error while running. Read the console. The error message names the line.
The editor looks different and Run is greyed outYou are in another mode. Switch the top-right menu back to Java.
The window is blankThe circle has already left the window. Press Stop (the square button) and Run again, and watch the top edge.
Processing asks to create a folder when you open a fileExpected. A sketch has to live in a folder with its own name. Say yes.
For the port step

Running plain Java

Each session ends by rewriting the sketch as standard Java with a main method and no window. Processing is not the tool for that part. Use any one of these:

The editor you already use

BlueJ, jGRASP, IntelliJ IDEA, VS Code, Eclipse: any of them will do. Make a new class whose name matches the file, paste, and run.

The command line

With Java 11 or newer installed, run a single file directly with no separate compile step:

java MovingBall.java

An online Java compiler

Nothing to install. Paste the whole file. If the site asks for a class name, use the one after public class.

Test it with this file, which is in the Session 1 download as plain-java/MovingBall.java:

public class MovingBall {

  public static void main(String[] args) {
    double y = 0;

    for (int frame = 1; frame <= 5; frame++) {
      System.out.println("frame " + frame + ": drew at y = " + y);
      y = y + 2;
    }
    System.out.println("after frame 5, y = " + y);
  }
}

Expect  Six lines of text:

frame 1: drew at y = 0.0
frame 2: drew at y = 2.0
frame 3: drew at y = 4.0
frame 4: drew at y = 6.0
frame 5: drew at y = 8.0
after frame 5, y = 10.0

One rule in every editor: the file name matches the public class name exactly. public class MovingBall lives in MovingBall.java. Processing never asks you to think about this. Plain Java won’t compile without it.
