Questions

Before you join the interest list

Is Processing the same as p5.js?

No. They share a creative coding philosophy and similar drawing ideas, but this camp uses Processing's Java mode. That matters because AP Computer Science A is a Java course. p5.js uses JavaScript.

How does this align with AP Computer Science A?

Every visual task is paired with a standard-Java transfer: method writing, control flow, class design, arrays, ArrayList, 2D structures, testing, or tracing. Processing is the visible context, not the exam language substitute.

Do I need to know Processing already?

No. The first session begins with sketch structure and the small set of Processing calls needed for the camp. Existing Java knowledge is the more useful starting point.

Is this an official College Board workshop?

No. This is an independent CC Fest Camp informed by the current AP Computer Science A course framework.

When does the camp meet?

The published schedule is five Sundays: November 8, 15, and 22, and December 6 and 13, 2026, from 7–9 a.m. PT / 10 a.m.–noon ET. There is no meeting November 29. Every session also works on your own. See the schedule and session materials.
