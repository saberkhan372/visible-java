The camp concept

Creative coding as an AP teaching surface

CC Fest is a volunteer-run creative coding education community. Learn more about CC Fest.

Processing gives abstract Java ideas somewhere to live. A field controls a position. A Boolean changes a scene. A loop draws a pattern. An array of objects becomes a simulation students can see, test, and explain.

The goal is not to replace AP-style reasoning with graphics. It is to build a visible model first, then carry the same variables, methods, classes, and algorithms into standard Java and written AP tasks.

Who this is for

  • Current and future AP Computer Science A teachers
  • Introductory Java teachers looking for a creative project layer
  • Creative coding educators moving from p5.js toward Java
  • Instructional coaches supporting project-based computer science

No prior Processing experience is required.

Session arc · Session 1 is ready

Four sessions, then an optional classroom studio

Each session moves from a visible experiment to an AP transfer task. Participants predict, run, revise, trace, and leave with something they can adapt.

  1. 01
    Sketch structure

    From sketch to Java

    setup(), draw(), variables, methods, scope, and what Processing supplies behind the scenes.

    draw() → repeated call
  2. 02
    Control flow

    Logic you can see

    Conditionals, loops, state, input, debugging, and animations that can be paused and traced.

    if (state) → scene
  3. 03
    Object design

    Objects become worlds

    Classes, constructors, arrays, ArrayList, and collections of visual objects with distinct state and behavior.

    class → many instances
  4. 04
    AP transfer

    From creative project to AP task

    Translate Processing work into standard Java, AP-style methods, systematic tests, tracing, and written reasoning.

    sketch → exam Java
  5. +
    Optional studio

    Adapt, teach, and share

    Participants adapt one project for their own classroom, test the AP connection, and share unfinished or finished work.

    remix → classroom

Questions

Before you join the interest list

Is Processing the same as p5.js?

No. They share a creative coding philosophy and similar drawing ideas, but this camp uses Processing's Java mode. That matters because AP Computer Science A is a Java course. p5.js uses JavaScript.

How does this align with AP Computer Science A?

Every visual task is paired with a standard-Java transfer: method writing, control flow, class design, arrays, ArrayList, 2D structures, testing, or tracing. Processing is the visible context, not the exam language substitute.

Do I need to know Processing already?

No. The first session begins with sketch structure and the small set of Processing calls needed for the camp. Existing Java knowledge is the more useful starting point.

Is this an official College Board workshop?

No. This is an independent CC Fest Camp informed by the current AP Computer Science A course framework.

Are the dates final?

Not yet. The interest form is being used to choose dates, times, and the right balance of live and asynchronous participation.
