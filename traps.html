Predict the output

Read the code. Decide what it prints. Then reveal the answer. Being wrong here is the point — a trap you fell for once is a trap you will never fall for again, and every one of these has cost somebody real points.

There is deliberately no Run button. Neither is there one in Bluebook on exam day. If you find yourself wanting to paste these into an editor to check, that is precisely the habit this page exists to break.

When you are ready for volume

  • CodingBat — hundreds of short problems with instant checking. Start with Warmup-1, then Logic-1, String-1, Array-1. The AP-1 set is built from old exam questions.
  • CodeStepByStep — a larger bank at the same level, useful once CodingBat starts feeling easy.
  • AP Classroom topic questions — the only bank actually written for the 2025 course. Ask your teacher to assign them.
