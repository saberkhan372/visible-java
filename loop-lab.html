Nested loops · Unit 2

Loop lab

In a pattern, each row is one pass of the outer loop. The inner loops decide how many spaces and stars that row gets. Write those two counts, then watch every print happen.

Predict first, then run. If you can say what a row will look like before it prints, you understand the loops.

01 · Patterns

Build a shape, one print at a time

Pick a shape to match. Write how many spaces and stars row number row needs, using row, ROWS, whole numbers and + - * / %. Math.min, Math.max and Math.abs work too.

Stuck? Count each row of the target first

Read down each column. When row goes up by one, what happens to the spaces? To the stars? That change is your expression.
