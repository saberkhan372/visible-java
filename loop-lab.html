Loops · Unit 2

Loop lab

In a pattern, each row is one pass of the outer loop. The inner loops decide how many spaces and stars that row gets. Write those two counts, then watch every print happen.

Predict first, then run. If you can say what a row will look like before it prints, you understand the loops.

01 · Patterns

Build a shape, one print at a time

Pick a shape to match. Write how many spaces and stars row number row needs, using row, ROWS, whole numbers and + - * / %. Math.min, Math.max and Math.abs work too.

The trace table gets a row each time row <= ROWS is checked, including the last check, the one that ends the loop. Predict each row’s counts in the blanks, then step to see if you were right.

Trace table

Fill in the blanks before you step. Each one fills in when its loop starts.

Stuck? Count each row of the target first

Read down each column. When row goes up by one, what happens to the spaces? To the stars? That change is your expression.

02 · Counting

How many times does the inner body run?

Change any part of either loop header: where it starts, how it compares, where it ends and how it updates. Then commit to a number, or decide the loop never stops, and check. Each dot is one run of the inner body, and each row of dots is one pass of the outer loop. The inner loop may use x.

for (int x = ; x ; )
for (int y = ; y ; )
System.out.println("Hi");

Updates can be x++, x--, x += 2, x -= 2, x *= 2 or x /= 2, with any whole number.

03 · Tracing

Trace a while loop, one step at a time

Each step either checks the condition or runs one statement. The trace table gets a row for every pass through the body, so you can see exactly when each variable changes and why the loop stops. Pick an example or write your own.
