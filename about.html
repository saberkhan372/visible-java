About

Made by teachers.
Built on Processing.

Visible Java is a free educator workshop and learning studio from CC Fest. It uses Processing to make Java ideas visible, then carries them into plain Java for the classroom.

01 / Who teaches it

Two teachers.
One workshop.

Questions about the workshop, the course, or the site? Email Saber.

  1. 01

  2. 02

02 / Who makes it possible

A community
and its tools.

Visible Java stands on free software and a community that has shared creative code for years.

  1. 01

    CC Fest ↗

    A free and friendly gathering for creative coding: workshops, talks, and community. CC Fest has been gathering creative coders since 2016. Visible Java is a CC Fest camp.

  2. 02

    Processing ↗

    Free, open-source software for learning to code through visual work. Every Visible Java sketch starts in its Java mode.

  3. 03

    Processing Foundation ↗

    The nonprofit that develops and supports Processing, p5.js, and the community around them.

03 / How it’s made

Shared freely.
Revised in public.

Every sketch, handout, and teacher guide is free to use and adapt. After each live session, we revise the materials using the questions and troubleshooting that came up. The site was built with help from AI coding tools.
