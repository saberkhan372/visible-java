# Visible Java Session 2 files

Session 2 (November 15, 2026) taught the draw loop, a first `if`, and a traffic light run as a PRIMM activity. These sketches follow what happened live. Open any folder in the Processing editor.

## What we did live

| Folder | What it is |
| --- | --- |
| `Wraparound/` | Mini-lecture: a car that wraps around and a bus that does not. |
| `Stoplight/` | Mini-lecture: a `boolean` light flipped with the space bar. |
| `TrafficLight/` | The traffic light starter. Only red is clickable. Rebuilt from the recording of Joshua Hans's Pickcode lesson *visible java traffic*, which is the original. |
| `TrafficLightCheckpoint/` | One way to finish it: all three lights clickable, the light sets the car's speed, and the car wraps around. |
| `TrafficLightTimer/` | The checkpoint plus a counter that changes the light every 180 frames. |
| `traffic-light-directions.md` | The directions to work from before Session 3. |
