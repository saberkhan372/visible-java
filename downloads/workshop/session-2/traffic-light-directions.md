# Traffic light: before Session 3

Do what you have time for and bring it to the start of Session 3 on Sunday, November 22, 7-9 a.m. PT / 10 a.m.-noon ET.

Open *visible java traffic* in Pickcode. In the Processing editor, `TrafficLight` in this download is the same starter.

1. **Predict.** Read the code before running it. What will you see? What happens when you click each light?
2. **Run.** Click all three lights. Were you right?
3. **Investigate.** Find the code that checks a click on the red light. Why can't you get back to green?
4. **Modify.** Make yellow and green clickable.
5. **Make.** Drive on green, slow on yellow, stop on red. Bonus: wrap the car around the screen.
6. **Put the light on a timer.** Make it change by itself every few seconds, with your own counter or with `frameCount % 180`.

**Stuck?** The recap has one way to make the clicks work and both timer versions: https://saberkhan372.github.io/visible-java/recap-2.html. `TrafficLightCheckpoint` and `TrafficLightTimer` in this download are finished versions to compare with.

**Something to think about.** In the debrief, someone asked whether each light could be its own object. Each light has a center, a bright color, and a dull color, and the same code runs for all three. Session 3 starts there.

**Share.** If you would like your light looked at on Sunday, post a screenshot or your code in the workshop's Google Classroom. Posting is optional.
