Processing for AP CS A.

A small studio for educators: four hands-on workshops and a classroom studio. Each one starts with something you can see and change, connects it to standard Java, and ends with an activity you could teach. It’s built for AP CS A, and useful well beyond it. No Processing experience is required.

How every session runs

Run it. Predict it. Change it. Port it.

One small visual system grows across the workshop: a moving shape becomes a responsive character, then a collection of objects, then a model that runs without its graphics. Make it an artwork, a garden, a science model, or a game. Each session takes it through four moves.

01 · Run

Get it moving

Everyone runs the same short sketch in the first ten minutes. Nothing else starts until it does.

02 · Predict

Commit before you look

Slow the sketch down and write down what the next few frames will print. Then run it and compare.

03 · Change

Change one thing

Short missions, each with an expected behavior, so you know when you have it and when you don’t.

04 · Port

Make it exam Java

Rewrite the idea as plain Java with no window. Its console output has to match what the sketch printed.

Before Session 1 · about 20 minutes

Get ready

Do these once, before the first session, so the live time goes to the ideas rather than installers.

  1. Use a laptop or desktop you can install software on

    macOS, Windows, or Linux. The Processing editor does not run on tablets, and Chromebooks need extra setup. School laptops sometimes block installs, so check early. If either is a problem, email ahead and we will plan around it.

    A browser-only option has been requested. We are testing one, but desktop Processing is the setup every activity is checked against, so plan on that.

  2. Install Processing and run one sketch

    Follow Your first sketch. It covers the download, Java mode, the Run button, and what you should see. You are done when a circle slides down the window.

  3. Have a way to run plain Java

    Any Java editor you already use works. If you don’t have one, Running plain Java covers three options, including a no-install one.

  4. Download the Session 1 files

    session-1-files.zip contains four sketches, three Java files, and an editable student handout and teacher guide. Unzip it somewhere you can find again.

  5. Optional: skim one comparison

    Compare shows ten small programs written three ways. Reading the second one, Something that moves, previews Session 1.

Live or on your own

Every session works without the meeting

Come live, follow along on your own schedule, or mix the two. Each session page has an On your own route, and every session can be entered from its checkpoint files, so missing one doesn’t strand you.

Runnable files

Starter, checkpoint, and completed versions of every sketch, plus the plain-Java counterparts.

Two levels of challenge

A supported modification everyone can finish, and an independent extension for anyone who wants more.

Handouts you can edit

A student activity and a teacher guide with expected answers and likely misconceptions, in plain text that’s easy to adapt or translate.

Answers explained

Every prediction and debugging task has its answer and the reasoning behind it.

A colleague exchange

One discussion prompt per session, with an example response. Share yours where the cohort shares work.

A classroom adaptation

A 20–30 minute task that turns the session into something for your own students.

Who this is for

Teachers bringing Java into view

Current and future AP Computer Science A teachers, and just as much the teachers who don’t teach AP: intro programming, creative coding, makerspaces, science and technology, and the coaches who support them. AP terms are explained as they come up, and every session names a classroom use outside AP.

Comfort reading basic Java helps. Processing experience does not matter: Session 1 assumes you have never opened it.

What success looks like

  • Explain how your program’s state changes
  • Change it on purpose, and predict the result
  • Show the Java connection in a plain-Java version
  • Leave with one activity ready for your own students
