01 / The workshop

One idea grows.
Five sessions take it further.

A moving shape becomes a character, a collection, and a model that runs without graphics. Each meeting has a 90-minute core and 30 optional studio minutes.

  1. 01Make state visibleVariables, motion, and prediction. Leave with a 30-minute classroom activity.Nov 8↗
  2. 02Make decisions visibleBoundaries, input, and loops. Build a visual debugging lab.Nov 15↗
  3. 03Make objects visibleClasses and arrays. Give each object a state of its own.Nov 22↗
  4. Nov 29 / Thanksgiving break. No meeting or required work.
  5. 04Make learning transferableSeparate the model from the drawing. Test it in plain Java.Dec 6↗
  6. 05Classroom studioAdapt, share, and revise. Leave with a classroom-ready lesson.Dec 13↗
Joining on your own?

Every session has an “On your own” route, checkpoint files, explained answers, and editable handouts. Start at Session 1 or pick up at any session’s checkpoint.

02 / The rhythm

See it. Question it.
Make it yours.

Four moves connect a sketch to the Java underneath.

  1. 01 / Run

    Get it moving.

    Start with a small sketch that works.

  2. 02 / Predict

    Call the next frame.

    Commit to an answer, then check it.

  3. 03 / Change

    Change one thing.

    Make an intentional edit. Explain the result.

  4. 04 / Port

    Keep the idea.

    Carry the same behavior into plain Java.

03 / Before you begin

Twenty minutes.
Then you’re ready.

Basic Java familiarity helps. Processing starts from the beginning. AP teachers, creative coding educators, and teachers beyond AP are welcome.

  1. 01

    Install Processing. Run your first sketch. ↗

    Use a laptop or desktop. You’re ready when a circle moves down the window.

  2. 02

    Choose a way to run plain Java. ↗

    Your usual editor works. The setup guide also includes a browser option for Java.

  3. 03

    Download the Session 1 files. ↓

    Sketches, Java programs, a student handout, and a teacher guide.

Using a Chromebook, tablet, or school-managed device?

Desktop Processing is the supported setup. Chromebook installation depends on Linux access, and tablets do not run the desktop editor. A browser setup has not been verified for every Processing activity. Read the setup guide or email Saber to plan ahead.
