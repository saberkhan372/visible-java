Section II

Four questions, ninety minutes

Free response is 45% of your score and it is the half you can prepare for most directly, because the four questions have been remarkably consistent in shape for years. You are not being asked to invent anything. You are being asked to write ordinary code that does exactly what the prompt says.

What the four questions are

#PointsShapeWhat you actually do
Q1 7 Methods and Control Structures Two methods, or a constructor and a method. Part A (4 pts) wants loops and conditionals plus calls to other methods in the class. Part B (3 pts) always requires calling String methods — so know all six on the reference sheet.
Q2 7 Class Design Design and implement a whole class from a table of example interactions. It must contain a class header, instance variables, a constructor, and a method — that is the literal checklist. Practise until the skeleton is muscle memory.
Q3 5 Data Analysis with ArrayList One method that uses, analyses and manipulates data in an ArrayList — often two lists of objects compared against each other. Note it is specifically ArrayList, not plain arrays.
Q4 6 2D Array One method over a grid. Nested loops, almost always row-major. The hard part is usually keeping your indices straight, not the algorithm.

25 points across 90 minutes. Question 1 and Question 2 are worth more than Question 3 — if you are running short, that is where to spend the time. Structure and point values are from the Course and Exam Description effective Fall 2025.

Before you practise

Not every old question still counts

Released free-response questions go back to 2004 and they are all still online. Many of them test things that were removed from the course in 2025. College Board says so themselves: the archived questions "do not completely align" with the current exam.

Skip a question if it asks you to…

  • write a subclass, or use extends or super
  • implement an interface
  • write a recursive method

All three were cut. A question built around any of them cannot appear now.

Prioritise

  • 2020 and later — closest to the current course
  • anything on 2D arrays, ArrayList, or writing a standalone class
  • the 2025 paper, first — it is the most recent signal you have

Everything is free, from the source: AP Central past exam questions. Download the Free-Response Questions PDF for the prompt and the Scoring Guidelines for the official answer. Do not trust a solution you found anywhere else until you have checked it against the guidelines.

Method

How to read one

First

Read the given code, not the story. Every question opens with a class you are handed. The methods in it are there because you are expected to call them. If the prompt gives you a getPrice(), use it — do not reach into the field directly and do not rewrite it.

Then

Copy the method header exactly. Return type, name, parameter types, parameter order. It is printed in the prompt. Retyping it wrong is the cheapest possible way to lose points, and it happens constantly.

Then

Find the boundary case before you write the loop. Empty list, one element, nothing matches, everything matches. Most rubrics have a point sitting on one of these.

Always

Write something. Partial credit is real and it is generous. A loop that traverses the right structure earns points even if the body is wrong. A blank answer earns nothing. Never leave a part empty because you could not finish part (a) — parts are scored independently, and you may call a method from part (a) in part (b) even if you never wrote it.

Never

Don't write a main unless asked. Don't add import statements. Don't print anything unless the question says to print — if it says return, return.

Worked practice

  • CupcakeMachine, StepTracker, and Time from the remixed class-creation set — work them one rubric point at a time before attempting a blank page.
  • The array, ArrayList, and 2D-array FRQ sets in the course folder — begin with the scaffolded copies, then repeat without the scaffolds.
  • Mixed-up code FRQ practice from the imported packets — put the provided lines in order as a bridge to writing from blank.
  • Annotated FRQ solutions — free, and explains why a rubric point exists.
  • Timed course practice — once you are close, sit at least one full 90-minute section before May.

Practise by hand at least twice. The exam is on a computer, but Bluebook will not compile your code, autocomplete a method name, or tell you that you forgot a semicolon. Writing two full questions on paper is the fastest way to find out which parts of the syntax you actually know.
