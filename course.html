02 / The connection

You can see the idea.
Now name what it does.

In Processing, a changing variable moves a shape. In plain Java, the same state belongs to an object. The graphics change; the reasoning carries over.

What a sketch looks like
float y = 0;

void setup() {
  size(400, 400);
}

void draw() {
  background(255);
  ellipse(200, y, 40, 40);
  y = y + 2;
}
What the exam wants
public class Ball {
  private double y;

  public Ball() { y = 0; }

  public void move() { y = y + 2; }

  public double getY() { return y; }
}

// somewhere else entirely:
Ball b = new Ball();
for (int i = 0; i < 3; i++) {
  b.move();
  System.out.println(b.getY());
}
