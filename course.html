AP Computer Science A · for students

You already write Java.
This year you make it formal.

This is a full AP CS A course: the pacing calendar, the units, the free-response work, and the tools. What makes it different is that it never starts from zero. If you have written Processing sketches, in a class, a camp, or on your own, everything here is anchored to them: the sketches, the classes, the arrays of objects, the grids. You are not learning Java. You are learning the rest of it.

New to Processing? Every lesson still works in plain Java, and Your first sketch gets you drawing in fifteen minutes if you want the visual side too.

What a sketch looks like
float y = 0;

void setup() {
  size(400, 400);
}

void draw() {
  background(255);
  ellipse(200, y, 40, 40);
  y = y + 2;
}
What the exam wants
public class Ball {
  private double y;

  public Ball() { y = 0; }

  public void move() { y = y + 2; }

  public double getY() { return y; }
}

// somewhere else entirely:
Ball b = new Ball();
for (int i = 0; i < 3; i++) {
  b.move();
  System.out.println(b.getY());
}

Same program. The global became an instance variable, float became double, draw() became somebody else's loop, and the picture became three lines of text. That seam runs through the whole year — Compare shows ten more, each in three runnable versions.

The good news first

The course got smaller in 2025

College Board rewrote AP CS A for the 2025–26 school year. Ten units became four, the exam moved into Bluebook on a computer, and a stack of topics was cut outright. If you are looking at an older review book or an older website, it is teaching you things that can no longer appear on the exam.

Cut — don't study these

inheritance polymorphism extends super interfaces writing recursion

The course description says it outright: "Designing and implementing inheritance relationships are outside the scope of the AP Computer Science A course and exam." You should still recognise the word superclass if it turns up in a question — you will simply never be asked to build one. If a practice question wants a subclass, it is out of date.

Added — and barely covered elsewhere

text files Scanner data sets tracing recursion

Reading a file, pulling numbers out of it, and reasoning about which data you'd need to answer a question. Most review sites have not caught up yet.

Placement

Four things you are actually missing

Nearly everything else on the syllabus is a variation on something you have already shipped. These four are not, and they are where the year is won or lost.

Static context

The Processing editor hid main from you. Now it's back, and "non-static method cannot be referenced from a static context" becomes the error you see most often. Nothing in a sketch prepares you for it.

Reading, not building

Processing rewards making things. College Board scores the multiple choice against five skills, and the largest by a distance is Analyze Code, at 37–53% — more than writing code, which is 22–38%. Up to half the section is reading somebody else's program with no Run button.

References and aliasing

You have made hundreds of objects and traced approximately zero. After p1 = p2;, what does p1 print? This is heavily tested and it is the most common wipeout.

Data you didn't invent

Reading a text file with Scanner, parsing it, and working with data sets. New to you, and new to the course as of 2025 — so almost nobody has good material on it yet.
