Unit by unit

The path

This course remixes the handouts, labs, assessments, and examples already in the course folder into the current four-unit AP CS A sequence. This page is the broad route through that material, written for someone who already knows how to write a loop. Skim what you know. Slow down where it says to.

All four units now have workbook overviews and meeting-by-meeting lesson pages. Every lesson centers AP Java; a Java + Processing extension is available when it helps students transfer what they already know. Use the broad route here, then enter the detailed workbook for the unit you are studying.

The course spine is local: the lesson pages, remixed handouts, labs, and current College Board topic sequence. Outside sites are optional practice, not the curriculum students must follow.

The shape of the year

Where the time goes

Five 50-minute periods a week gives this plan 140 class days over 28 weeks, about 117 hours, with eight flex days built in. If you have written Processing sketches, you start ahead on the basics, so the trade is deliberate: Units 1 and 2 move fast, Units 3 and 4 do not move fast at all. The calendar has every day.

  1. Weeks 1–5

    Unit 1 · Using Objects and Methods

    22 days 15–25% of the multiple choice

    The first two weeks are a speed-run through things you already know. Then it slows right down for Strings, which get three full lessons — six days, far more than their share — because sketches almost never use them and Question 1 needs them every year.

  2. Weeks 5–9

    Unit 2 · Selection and Iteration

    23 days 25–35% — the biggest MCQ slice

    The most familiar unit and the most heavily tested one. Almost nothing here is new, so the work is speed: tracing loops accurately, under time. New bits are De Morgan's laws, string algorithms, and counting loop executions.

  3. Weeks 10–14

    Unit 3 · Class Creation

    25 days 10–18% of MCQ · 7 of 25 FRQ points

    Smallest unit by exam weight, and it still gets full time — because Question 2 asks you to write a whole class, and sketch classes almost never use private and rarely return anything. static is genuinely new.

  4. Weeks 15–26

    Unit 4 · Data Collections

    58 days 30–40% of MCQ · 11 of 25 FRQ points

    Nearly half the year, because nearly half the exam. Arrays are review; everything else is not. Text files and ArrayList are new, 2D arrays are completely new, and searching, sorting and recursion arrive at the end. Picture Lab lands here — the most Processing-like thing in the course.

  5. Weeks 26–28

    Review

    12 days everything, under time

    A full timed multiple-choice section first, to find out what is actually weak. Then all four free-response types under real time limits, the Java Quick Reference end to end, and a Bluebook practice run.

  6. May

    AP Exam

    3 hours 42 MCQ (55%) · 4 FRQ (45%)

    Ninety minutes each side. Digital, in Bluebook, with the Java Quick Reference available on screen — and no Run button.

One thing to watch: your longest break. Wherever it falls in Unit 4, whatever is shaky going in will still be shaky coming out unless you touch it. The plan’s Retrieval day is built to sit right after it. Ten minutes of traps a day over the break is enough.

Unit 1 · Using Objects and Methods

15–25% Open the 11 lessons →
Skim

Lessons 1 and 2 — program entry, output, variables, types, expressions, casting, and compound assignment.

You know almost all of this. Focus on two Java differences: AP code uses double rather than Processing's usual float, and integer division discards the fractional part.

Read

Lessons 3–9 — libraries, method signatures, the Math class, constructors, instance methods, aliasing, and String.

  • 1.11 Math class — where random(), abs() and sqrt() went.
  • 1.15 Strings — the biggest single gap in the whole course for you. Across a full year of Processing sketches we measured, 140 files, there is not one call to substring, indexOf, or compareTo. You drew strings; you never took them apart. Free-response Question 1 Part B requires these every single year.
Slow down

References and aliasing. Nothing you did in Processing prepares you for this and it is worth more points than it looks.

  • Traps 11 and 12 on this site, then step both through Java Tutor.
  • Your teacher's Tracing References and Changing People labs. Hand-draw the diagram before you run anything.
Drill
  • CodingBat Warmup-1 — twenty minutes, gets you used to writing a method with a return type.
  • CodingBat String-1 — do all of them. This is where substring and indexOf become automatic.
Check
  • Can you write a class header, a constructor, and a method that returns a value, from memory, with no autocomplete?
  • Given String s = "computer", can you say what s.substring(2, 5) is without counting on your fingers twice?
  • Can you explain why a == b can be true for two strings and still be the wrong thing to write?

Unit 2 · Selection and Iteration

25–35% Open the workbook →
Skim

The remixed loop and selection materials cover booleans, if, nested if, compound conditions, while, for, and nested loops.

This is the largest slice of the exam and you already know all of it. Your job here is speed and accuracy under time pressure, not new concepts. Do not let the familiarity fool you into skipping the practice.

Read
  • 2.6 De Morgan's Laws — probably new. How to push a ! through an && or ||, and why it flips.
  • 2.10 String algorithms — looping through a string one character at a time.
  • 2.12 Informal runtime analysis — counting how many times a loop body runs. New, and easy points.
Slow down

Short-circuit evaluation (trap 8) and tracing nested loops (trap 9). Both appear almost every year and both are pure tracing, which is exactly the muscle you have not built.

Drill
  • CodingBat Logic-1 and Logic-2 — the best boolean practice that exists.
  • CodingBat String-2 — loops over strings.
  • Your teacher's loop/if packet and Chapter 3 multiple-choice packet.
Lab

Magpie Chatbot Lab from the course folder — a College Board lab built out of if statements and indexOf. It doubles as String practice.

Check
  • Given a nested loop with the inner bound depending on the outer variable, can you count the total iterations in under a minute?
  • Can you rewrite !(a && b) without the outer !?
  • Do you know what 5 % 8 is, instantly?

Unit 3 · Class Creation

10–18% Open the 13 lessons →

Smallest unit, outsized payoff. One of your four free-response questions is always "write this class." Ten percent of the multiple choice, twenty-five percent of the writing.

Read

The remixed class-creation handouts and labs cover the full topic sequence.

  • 3.3–3.5 anatomy of a class, constructors, methods. You have done this in sketches; now do it with public and private in the right places.
  • 3.6 passing and returning object references — the aliasing material again, from the writing side.
  • 3.7 static — genuinely new. The PDE never made you think about it.
  • 3.8–3.9 scope, access, and this.
Slow down

Encapsulation as a graded habit. Instance variables private, accessors public, constructor sets every field. In a sketch this was optional style. On a rubric it is points.

Trap 13 for what static actually means; trap 11 for what a method can and cannot change about the caller's object.

Practice
  • Mixed-up code and write-code practice from the imported course packets.
  • Your teacher's Bank Account, Band Booster, and Tracking Grades labs — all three are "write a class with fields, a constructor, and a few methods," which is the exact FRQ format.
  • CupcakeMachine and StepTracker — released FRQ-style class-writing practice, worked and scored against the official criteria.
Skip

Older inheritance folders are marked optional because inheritance, extends, super, polymorphism and interfaces were all removed from the exam in 2025. Same goes for any Animal/Cow or Dog/Labrador style worksheet you come across. Interesting material, zero exam value — leave it for after May.

Check
  • Can you write a complete class — header, private fields, constructor, accessors, toString — on paper, correctly, in ten minutes?
  • Can you say why a static method cannot read an instance variable?

Unit 4 · Data Collections

30–40% Open the 30 lessons →

The big one. Well over a third of the exam, two of the four free-response questions, and the largest amount of material that is new to you. Budget accordingly — this unit is worth more than Units 1 and 3 combined.

Read

The remixed data-collections folder is organized in four passes:

  • Arrays (4.3–4.5) — familiar. You built whole worlds out of arrays of objects. Watch only the .length / .length() / .size() distinction and the enhanced for loop's limits.
  • ArrayList (4.7–4.10) — new for most of you. Unless you reached for one in your final project, you have not met it. Wrapper classes, and removal shifting every later index left.
  • 2D arrays (4.11–4.13) — completely new. Those same 140 sketches contain not a single [][]. Row-major order, nested loops, grid.length vs grid[0].length.
  • Searching, sorting, recursion (4.14–4.17) — new. Sequential and binary search; selection, insertion and merge sort.
New in 2025

4.2 Data Sets and 4.6 Using Text Files. Reading a file with Scanner, pulling values out line by line, and reasoning about which data you would need to answer a given question.

Completely new — sketches almost always make up their own data or read the mouse. They rarely open a file. And new to the course too, so most review books and websites have not caught up. Do not assume a resource covers this just because it looks thorough. Your teacher's Inventory Auditor, Weather Data Analyzer and Gradebook Validator labs are built for exactly this.

One warning: the reference sheet you get on exam day lists hasNext() but not hasNextLine() or hasNextInt(). Those work fine in a real IDE and appear in some practice labs — just don't build an exam answer on them.

Recursion

Tracing only. Since 2025 you are never asked to write a recursive method — only to read one and say what it returns, find its base case, or spot why it never terminates.

This makes recursion much easier than the reputation suggests. Use trap 18 and the folder's tracing examples. If your teacher assigns the older Power, Fibonacci or Palindrome labs, do them as tracing exercises: predict every return value before running anything.

Drill
  • CodingBat Array-1, Array-2, Array-3.
  • CodingBat AP-1 — built from real exam questions.
  • The imported multiple-choice packets, sorted by arrays, ArrayList, 2D arrays, and algorithms.
Lab

Picture Lab from the course folder. Manipulating images pixel by pixel with 2D arrays — mirroring, collage, edge detection. This is the closest the AP course comes to what you did in Processing, and it is the best possible way to make 2D arrays stick. If you only do one lab all year, do this one.

Check
  • Can you traverse a 2D array by row and by column without looking up which index is which?
  • Can you explain why removing from an ArrayList inside a forward loop skips elements?
  • Given a recursive method and an input, can you produce the return value on paper?
  • Can you open a file with Scanner and read it line by line from memory?
