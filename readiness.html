01 / How it works

Zoom to meet.
Pickcode to code.

No invite yet, or joining late? You can still join. Email Saber.

  1. 01

    Meet on Zoom.

    We say hello, get set up, and start coding together.

  2. 02

    Code in Pickcode.

    It runs Processing and Java in a browser. The directions come by email and in Google Classroom.

  3. 03

    Google Classroom is optional.

    Your invite comes by email. Recordings and notes live there, and you can post your work if you want feedback.

  4. 04

    Or work on your own.

    Every session has an on-your-own route if you can’t join live.

Recordings. We will ask for your consent before we record. Live sessions are recorded and shared in the workshop’s Google Classroom, and we use Zoom’s AI recap, so keep your camera off whenever you like. We also use transcripts, with names taken out, to improve the materials. If you would rather your words stay out of them, tell us in the Zoom chat or by email.

03 / Setup

Want a head start?
Run two programs.

This is optional. Use a laptop or desktop. Pickcode runs in a browser, so most people will not need to install anything. If something doesn’t work, bring it to the first session.

  1. 01

    Join the Pickcode class.

    The directions come by email and in Google Classroom. You’re ready when a circle moves down the window. Prefer the desktop editor? Install Processing ↗

  2. 02

    Download the Session 1 files. ↓

    Sketches, Java programs, a student handout, and a teacher guide.

  3. 03

    Run the plain-Java example. ↗

    Run plain-java/MovingBall.java from the download. You’re ready when it prints five frames.

Using a Chromebook, tablet, or school-managed device?

Use Pickcode, which runs in a browser, so it should work unless your school blocks it. The join link comes by email and in Google Classroom. Tell us if you cannot open it.
